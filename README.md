# Spring Boot Projects

This repository contains a small collection of independent Spring Boot projects used for learning, experiments, and backend examples.
This repository is created as a part of the learning in the course: [Java Spring Boot Full Stack: eCommerce Project Masterclass](https://www.udemy.com/share/105fji3@ZCj3O6wAKh5HWtslzKSww8BIKTyfLpE3RO9vLpUKqhP0VhY4dcIQ-7Trx7tNHnOaTg==/)

## Included modules

- [ecommerce](./ecommerce) — e-commerce sample application built with Spring Boot, Spring Web MVC, JPA, validation, and H2 database.
- [learning](./learning) — lightweight Spring Boot learning application with a basic web API setup and MySQL integration.

## Prerequisites

- Java 17+
- Maven 3.9+
- Optional: IntelliJ IDEA or VS Code with Java support

## Notes

- These are separate Spring Boot applications, not a single multi-module Maven project.
- Each project has its own `pom.xml` and can be run independently.
- The root README is intended as a quick index for the workspace.
